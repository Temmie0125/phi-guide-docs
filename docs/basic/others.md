## Data

是Phigros游戏中通用的货币，可以用于购买单曲精选集曲目。  
Data可以通过游玩或是首次浏览收藏品两种方式获得。每个收藏品首次浏览时可获得1.5MB。  
当玩家一局游戏得到880000分及以上时就可以获得Data，获得量与谱面等级、游玩分数相关。  
~~当前版本游玩18级谱面最多获得256KB~~  
![image](/images/LAK4BXBAACQDA.png)

当谱面单次游玩成绩达到880000时，获取的Data量与成绩呈线性相关：  
当谱面单次游玩成绩恰好为880000时，获取的Data量为可获取最大值的60%。  
当谱面单次游玩达到了φ评级时，获取的Data量达到最大值。  
用公式表示为：$Data=\frac{Score-700000}{300000}\times MaxData$  
特别地，首次游玩游戏玩法教学（Introduction）后，结算时无论游玩成绩如何，都可以获得32.00MB。  
  
Data的单位换算和现实的数据单位换算相同，1 MB = 1024 KB，1 GB = 1024 MB，1 TB = 1024 GB。~~但是正常情况下应该还没有人能攒到1 TB~~。

## 重演

于3.5.0版本追加。  
“重演”功能开启后，按照解锁某一主线章节的特定方法进行游戏/（3.16.0新增）直接游玩带有异象的曲目，即可重新体验该解锁过程中遇到的异象（如谱面特效、剧情动画等）。  
无论是在曲目列表选择，还是在游玩特定曲目后自动跳转，所有歌曲在游玩后均会正常结算，但根据异象具体情况不同，可能不会显示结算画面。  
“重演”功能开关在通关所有主线章节曲目后，会出现在收集品展示页（官方称呼为“土星系统初始页”）右下角。该功能每次打开游戏时默认为关闭状态。  
在开启“重演”后，在主线第八章进入“土星系统”（Phigros主界面点击第八章“BOOT”按钮，或在第八章曲目选择界面点击上方“OS”字样图标）后，所有歌曲将显示为未解锁状态，可通过特定条件下打歌解锁或切换到曲目选择界面游玩对应曲目异象。
